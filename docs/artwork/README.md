# Artwork provenance

The repository cover and app icon were generated for this project with OpenAI's built-in image-generation tool on 2026-10-23. They are branding artwork, not screenshots or evidence of application behavior. No private conversation images were used as input.

- `docs/images/cover.png`: generated cover, used without retouching.
- `assets/icon-v2.png`: current generated transparent launcher icon. The build resamples it into the sizes required by a macOS `.icns` container. No official product icon is included.
- `assets/icon.png`: earlier bilingual icon, retained as an alternative.
- `docs/images/codex-table-after.png` and `codex-code-after.png`: real desktop screenshots contributed by the user. Only rectangular, pixel-preserving cropping was applied with permission. Personal UI was excluded. No generative editing, retouching or textual alteration was applied.

The generated artwork is distributed with the project under its MIT license, to the extent applicable rights exist. The rights to third-party names and trademarks are unaffected.

## Current icon prompt

The current icon's complete prompt is in [icon-v2-prompt.txt](icon-v2-prompt.txt). It was generated using the built-in image-generation tool, with transparency enabled and no input images.

## Cover prompt

Use case: ads-marketing. Create one polished wide GitHub repository cover banner, landscape 1792 by 1024 or similar wide landscape. Project title exactly: "Codex RTL for Mac". Subtitle exactly: "Arabic + English. In the right direction." Tiny footer text: "Community project · macOS". Visual style: premium editorial software identity, deep ink navy and warm ivory, cobalt blue and a restrained soft mint accent, crisp generous typography, lots of negative space. Visual concept: two flowing fine typographic ribbons meet in a softly lit glass rounded square, one carries a beautifully readable Arabic letter ع, the other a simple Latin A. Elegant bilateral motion implied by the curved ribbons. A subtle grid evokes ordered text columns. Delicate material depth, calm professional composition, no excessive gradients or generic AI glow. Title large at upper left in precise sans serif; sculptural bilingual motif on right. This is branding artwork, not a screenshot: no fake application window, no fabricated table, no product claims about security, no OpenAI knot logo, no Apple logo, no badges, no personal data. Make all English title text exact and clearly readable.

## Earlier icon prompt

Use case: logo-brand. Produce a square 1024x1024 macOS app icon artwork for an independent community project called Codex RTL for Mac. No words. One elegant rounded square filling about 85 percent of the canvas, deep ink navy ceramic and glass with a warm ivory Arabic letter ع and a cobalt blue Latin A, beautifully interlocking but both clearly distinct, a small mint accent suggesting right-to-left reading. Clean silhouette recognizable at 32px, generous internal spacing, restrained soft dimensional lighting and crisp edges. Premium professional software identity, not busy calligraphy. Outside the rounded square is fully transparent. No OpenAI logo, no Apple logo, no laptop, no shadows beyond the icon silhouette, no ribbons outside the square, no text or badges.
