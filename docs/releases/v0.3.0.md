The first public macOS release of Codex RTL for Mac. It improves Arabic-English paragraphs, tables and nested link labels while keeping code, paths and English phrases LTR.

## Downloads

- **Standard:** `Codex-RTL-for-Mac-v0.3.0.zip`. Includes universal Node.js for Apple silicon and Intel. Extract, move the app to Applications, then double-click.
- **Lite:** `Codex-RTL-for-Mac-Lite-v0.3.0.zip`. Uses an existing Node.js 22+ installation. Finder runtime discovery and an explicit Node path are supported.
- **Checksums:** `SHA256SUMS.txt` covers both ZIPs.

Both editions use the same renderer and the existing navy launcher icon.

## Included

- Consistent table-column alignment and cell spacing.
- Isolation for mixed Arabic-English phrases, numbers and units.
- Reprocessing of streamed content and rebuilt link labels.
- Automatic discovery of compatible ChatGPT.app or Codex.app installations.
- English and Arabic guides, customization instructions, a fictional demo prompt and cropped real-app screenshots.
- Tagged releases built by GitHub Actions after unit and browser checks, with archive verification on Apple silicon and Intel runners.

## Before opening

These apps are ad-hoc signed and are **not Apple-notarized**. Read the [installation guide](https://github.com/ahmedtolan2019/codex-rtl-mac/blob/v0.3.0/docs/installation.md) before first launch.

The launcher enables a loopback Chromium debugging port. Other local processes may use that interface to read or control the official app. Read the [security model](https://github.com/ahmedtolan2019/codex-rtl-mac/blob/v0.3.0/SECURITY.md). Quit the official app completely to close the port.

The official app bundle and update files are not changed. Future app changes can still require a launcher update.

## Verification scope

The core renderer was confirmed by the user on desktop version 26.1016.61520, build 21421. Automated tests exercise synthetic browser content and mocked launcher behavior. Release checks validate extracted signatures, checksums, bundled source and runtime execution on both Mac architectures. They do not open a signed-in Codex session or establish complete end-to-end compatibility on every Mac. See [compatibility](https://github.com/ahmedtolan2019/codex-rtl-mac/blob/v0.3.0/docs/compatibility.md).
