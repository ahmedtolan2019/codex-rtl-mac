Pipeline maintenance release. The renderer, launcher behavior and existing navy icon are unchanged from v0.3.0.

The release workflow now uses current GitHub actions running on Node.js 24, pinned to exact commits. The browser-test runner is pinned to Ubuntu 24.04 instead of a moving `ubuntu-latest` label. Both editions are rebuilt from this tag and verified on Apple silicon and Intel before publication.

## Downloads

- **Standard:** `Codex-RTL-for-Mac-v0.3.1.zip`. Includes universal Node.js. Extract, move the app to Applications, then double-click.
- **Lite:** `Codex-RTL-for-Mac-Lite-v0.3.1.zip`. Uses an existing Node.js 22+ installation.
- **Checksums:** `SHA256SUMS.txt` covers both ZIPs.

Follow the [installation guide](https://github.com/ahmedtolan2019/codex-rtl-mac/blob/v0.3.1/docs/installation.md). These community apps are ad-hoc signed and are **not Apple-notarized**.

The launcher leaves the official app bundle untouched, but enables a loopback debugging port that other local processes can potentially access. Read the [security model](https://github.com/ahmedtolan2019/codex-rtl-mac/blob/v0.3.1/SECURITY.md). Quit the official app completely to close the debugging session.

The checks cover mocked launcher behavior, synthetic browser rendering, extracted signatures, source consistency and runtime execution on both architectures. They do not open a signed-in Codex session. See [compatibility and verification scope](https://github.com/ahmedtolan2019/codex-rtl-mac/blob/v0.3.1/docs/compatibility.md).
